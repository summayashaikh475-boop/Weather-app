🌦 Weather App
This is a simple weather app made using Python.
It shows the current weather of any city you enter.

🚀 Features
Get real-time weather
Simple and clean interface
Easy to use

🛠 How to Run
Download or clone this project
Install required libraries
Run the file:
python gui.py

🔑 Note
This app uses an API key, so create a .env file and add your key:
API_KEY=your_api_key_here

💡 About
This project is made for learning and practice.
Beginner-friendly and simple to understand.
